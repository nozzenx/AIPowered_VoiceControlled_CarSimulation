# AI-Powered Voice-Controlled Car Simulation

An interactive car simulation developed with **Unity**, integrating **OpenAI Whisper** and **GPT models** to enable natural voice-based vehicle control.

The project allows users to interact with a virtual car through voice commands. Spoken instructions are converted into text using Whisper, then processed by GPT to interpret user intent and trigger the corresponding actions within the Unity environment.

## Key Features

- **Speech-to-Text:** Uses OpenAI Whisper to convert voice input into text.
- **AI-Powered Command Interpretation:** Integrates GPT models to understand natural language instructions and identify the intended action.
- **Dynamic Vehicle Control:** Executes AI-interpreted commands directly within the Unity simulation.
- **Natural Language Interaction:** Allows users to control vehicle functions without relying on traditional keyboard or button inputs.

## Supported Voice Commands

Users can interact with the vehicle using commands such as:

- Open or close the car doors.
- Open or close the windows.
- Switch between driving modes.
- Activate or deactivate vehicle features.
- Trigger obstacle-related interactions.

## Technologies Used

- **Unity**
- **C#**
- **OpenAI Whisper**
- **OpenAI GPT Models**
- **Speech-to-Text Processing**
- **Natural Language Processing (NLP)**

## Project Objective

The main objective was to explore the integration of large language models into interactive applications and demonstrate how natural language can be used as an interface for controlling in-game systems.

The project combines speech recognition, AI-based intent interpretation and real-time Unity interactions to create a more intuitive and intelligent user experience.
